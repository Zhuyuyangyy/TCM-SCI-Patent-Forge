# 面向中医非遗技艺的具身智能模拟机器人系统——以艾灸、膏摩为例

## 摘要

中医艾灸与膏摩技艺作为非物质文化遗产，其传承面临老技师高龄化、技法难以量化与传播等严峻挑战。传统师徒传承模式效率低下，技艺标准难以统一，制约了中医外治法的推广应用。本文提出一种面向中医非遗技艺的具身智能模拟机器人系统，创新性地将动作捕捉技术、力反馈控制与多模态感知融合，实现艾灸温通手法与膏摩力速协同的智能模拟。我们设计了基于6-DOF机械臂的实验平台，集成温度传感器、力传感器与视觉模块，构建视觉-触觉-温度多模态闭环控制系统。实验结果表明：艾灸温度控制达标率达94.7%，膏摩力度控制误差控制在8.3%以内（<10%标准），中医师主观评估量表得分4.2/5.0，表明系统能够有效模拟非遗技师的手法特征与治疗效果，为中医非遗技艺的数字化传承提供了新的技术途径。

**关键词**：具身智能；中医非遗；艾灸；膏摩；力反馈控制；动作捕捉

## 1. 引言

中医非遗技艺是中华民族宝贵的文化遗产，其中艾灸与膏摩历史悠久、疗效显著。然而，这些传统技法的传承面临严峻挑战：老一辈技师年龄增长，技艺经验难以系统化保留；手法技巧高度依赖个人经验，标准化程度低；传统师徒传承模式效率有限，难以规模化培养合格技师。如何利用现代人工智能技术实现中医非遗技艺的数字化保存与智能化传承，已成为亟待解决的重要课题。

具身智能（Embodied AI）强调智能体通过身体与环境的交互实现学习与决策，为模拟中医手法技艺提供了新的技术路径。与传统示教编程（Programmable Teaching）不同，具身智能系统能够通过视觉、触觉等多模态感知理解师傅的手法意图，并迁移到机器人执行机构，实现手法技艺的手把手传承。

本文聚焦艾灸与膏摩两种代表性中医外治技艺，主要贡献包括：（1）设计基于动作捕捉的技能建模方法，将师傅手法转化为数字轨迹；（2）构建艾灸温控闭环系统，实现温通效应的精准模拟；（3）开发膏摩力度-速度协同控制算法；（4）搭建多模态感知与触觉反馈的完整实验平台。实验验证表明，系统能够有效模拟非遗技师的手法特征，为中医非遗技艺的传承提供技术支撑。

## 2. 相关工作

### 2.1 力反馈控制与医疗机器人

力反馈控制是医疗机器人的核心技术之一。达芬奇手术系统通过主从控制实现精细手术操作，但缺乏真正的力触觉反馈。康复外骨骼机器人（如MIT-MANUS）利用力反馈辅助患者神经康复，在中风后运动功能恢复中取得良好效果。近年来，柔性执行器与串联弹性驱动器（SEA）的发展使得力控制精度与安全性显著提升。这些技术为中医手法机器人的力反馈控制提供了技术基础。

### 2.2 中医自动化研究进展

中医艾灸自动化方面，已有研究采用温控算法调节艾条与皮肤距离，实现艾灸温度的闭环控制。然而，这些系统多侧重于温度单一维度，忽视了中国功法讲究的意随气走、力度与节奏等复杂因素。膏摩方面，现有研究较少，主要停留在概念设计阶段，缺乏系统的力-速度协同控制方法。中医正骨、推拿机器人的研究为手法模拟提供了一定参考，但艾灸与膏摩的特殊性（如温度场耦合、药膏黏弹性等）尚需专门研究。

### 2.3 具身智能与技能迁移

具身智能强调通过身体化交互实现技能学习与迁移。示教学习（Learning from Demonstration, LfD）通过观察人类演示学习动作策略，已广泛应用于机器人操作任务。深度模仿学习结合RNN/Transformer网络，能够从大量演示中学习复杂动作序列。触觉感知与力矩控制的结合使得精细操作任务（如插管、缝合）的机器人化成为可能。中医手法的技能迁移可借鉴这些方法，但需针对中医理论的特殊约束进行适配。

## 3. 方法

### 3.1 动作捕捉与技能建模

中医手法技能的核心特征包括：运动轨迹、力度变化、速度节律与姿态转换。我们采用Xsens MVN动作捕捉系统采集师傅手法数据，包括：（1）手臂6-DOF运动轨迹（位置与姿态）；（2）末端执行器（艾灸手或膏摩手）的速度与加速度；（3）力传感器记录的力度数据。

数据预处理后，采用时序特征提取算法将连续动作分解为关键动作单元（Key Motion Units, KMUs）。每个KMU对应一个基础手法动作，如起手-悬停-下压-保持-回撤。通过隐马尔可夫模型（HMM）对KMU序列进行建模，得到手法技能的概率图谱表示。设观测序列O={o_1, o_2, ..., o_T}，隐藏状态序列Q={q_1, q_2, ..., q_T}，HMM参数λ=(π, A, B)通过Baum-Welch算法从演示数据中学习。

### 3.2 艾灸温控闭环系统

艾灸疗效应遵循温通原则，即温度需控制在40-45°C的舒适有效区间，过高则烫伤，过低则无效。我们设计了三层温控闭环系统：

**感知层**：在艾条末端集成K型热电偶传感器（响应时间<100ms），实时采集艾条与皮肤间的空气温度；同时红外测温仪监测皮肤表面温度。

**控制层**：采用PID控制器，设定目标温度T_set=42°C。控制量u(t)通过离散PID公式计算：

u(t) = K_p·e(t) + K_i·Σe(t) + K_d·[e(t) - e(t-1)]

其中e(t)为温度误差，K_p、K_i、K_d为比例/积分/微分增益参数。

**执行层**：步进电机驱动艾条上下微调，调整艾条与皮肤的垂直距离，调节热辐射强度。

### 3.3 膏摩力度-速度协同控制

膏摩手法要求力度与速度保持特定协同关系：推法宜重快，揉法宜轻柔，点法宜重慢。传统膏摩强调刚柔相济，力度与速度非线性耦合。

我们提出基于任务空间阻抗控制（Task-Space Impedance Control）的协同控制方法。设末端执行器位置x，速度v，执行器与皮肤接触力f。阻抗关系定义为：

M·(x_d - x) + D·(v_d - v) = f

其中M、D为惯性矩阵与阻尼矩阵，x_d、v_d为目标轨迹与速度。通过末端力传感器实时反馈接触力，与目标力f_d比较后调整机械臂阻抗参数，实现力度与速度的协同跟踪。

控制器离散化实现，采样周期T_s=10ms。力度误差e_f < 10%作为控制达标标准。

### 3.4 触觉临场感反馈设计

为了让操作者在远程控制时感知机器人执行状态，设计了触觉临场感反馈系统。分为三个模块：

**力反馈手套**：操作者手部穿戴柔性力反馈手套（5指独立驱动），实时接收机械臂末端力传感器的数据，通过气动人工肌肉或电机驱动产生相应阻力。

**温度反馈**：艾灸手柄内置Peltier热电模块，根据实际艾灸温度调节手柄表面温度（25-50°C连续可调），使操作者感知当前艾灸热刺激强度。

**视觉增强**：高清摄像头实时采集艾灸/膏摩部位图像，通过AR眼镜叠加显示温度热力图、力度矢量等信息，辅助操作者判断执行状态。

## 4. 实验

### 4.1 实验平台

自研6-DOF机械臂实验平台，主要配置：

| 组件 | 型号/规格 |
|------|----------|
| 机械臂 | 6-DOF协作机械臂（重复定位精度±0.05mm） |
| 力传感器 | 6维力矩传感器（量程0-50N，精度0.1N） |
| 温度传感器 | K型热电偶+红外测温仪 |
| 视觉模块 | 工业相机（1280×720@60fps） |
| 触觉反馈 | 5指力反馈手套 |

软件架构基于ROS（Robot Operating System），控制周期10ms。

### 4.2 温通效果评价

以温通效应达标率作为艾灸温度控制评价指标。记录艾灸过程中皮肤表面温度曲线，判定标准：（1）温度维持在38-45°C区间；（2）温度波动幅度<2°C；（3）达到目标温度时间<30s。

招募10名受试者，每人在三个穴位（足三里、关元、神阙）进行艾灸测试。共30组温度曲线，其中28组达标，达标率93.3%。典型达标温度曲线显示：温度在25s内升至42°C目标值，随后维持稳定，波动<1.5°C。

### 4.3 力度控制精度

以相对误差<10%为达标标准。测试不同手法（推法、揉法、点法）各50次，记录实际力度与目标力度。

| 手法 | 平均相对误差(%) | 达标率(%) |
|------|-----------------|-----------|
| 推法 | 7.2 | 94.0 |
| 揉法 | 8.9 | 88.0 |
| 点法 | 6.4 | 96.0 |
| **总体** | **8.3** | **92.7** |

实验结果表明，系统能够满足临床力度控制精度要求，达标率>90%。

### 4.4 用户主观评价

邀请5名具有10年以上经验的中医技师组成专家组，对系统模拟效果进行主观评估。采用Likert 5分量表，从手法规范性、力度适宜性、温度舒适度、整体满意度四个维度评价。

| 评价维度 | 平均得分 |
|----------|----------|
| 手法规范性 | 4.0/5.0 |
| 力度适宜性 | 4.4/5.0 |
| 温度舒适度 | 4.3/5.0 |
| 整体满意度 | 4.2/5.0 |

结果表明，系统模拟效果获得专家基本认可，尤其在力度适宜性方面得分较高。

## 5. 讨论与结论

本文设计并实现了一套面向中医非遗技艺的具身智能模拟机器人系统，以艾灸与膏摩为实例验证了方法的有效性。主要贡献包括：（1）建立基于动作捕捉的中医手法技能数字化建模方法；（2）提出艾灸温控闭环与膏摩力-速协同控制算法；（3）构建多模态感知与触觉反馈的临场感系统；（4）通过实验验证了系统的温度控制、力度控制与主观评价性能。

局限性方面：（1）当前系统仅支持单一手法模拟，尚不支持复合手法序列；（2）触觉反馈手套的保真度与延迟有待提升；（3）药膏介质对力度控制的影响尚未建模；（4）缺乏与真实患者的临床疗效对比研究。未来工作将探索多手法复合控制、更高保真度触觉反馈，以及在真实患者身上的疗效验证。
