# TCM-DigitalTwin-Constitution: 中医体质数字孪生系统

> 基于马尔可夫链与反事实推理的体质状态建模与干预分析系统

---

## 项目概述

TCM-DigitalTwin-Constitution 是一个将中医体质理论与数字孪生技术深度融合的智能系统。系统通过构建九种体质的动态演化模型，支持体质状态预测、反事实干预模拟和多场景干预比较，为中医"治未病"提供个性化决策支持。

### 核心特性

| 特性 | 描述 |
|------|------|
| **体质状态向量** | 九种体质的多维向量表示 |
| **马尔可夫链演化** | 体质状态转移概率矩阵 |
| **反事实引擎** | 多干预方案对比与效果预测 |
| **可视化仪表盘** | 雷达图、轨迹图、风险对比图 |
| **多干预支持** | 运动、饮食、推拿、艾灸 |

## 九种体质定义

| 体质类型 | 阴阳倾向 | 气血状态 | 主要特征 |
|---------|---------|---------|---------|
| 平和质 | 阴阳平衡 | 气血调和 | 体态适中，精力充沛 |
| 气虚质 | 阳偏虚 | 元气不足 | 易疲乏，气短懒言 |
| 阳虚质 | 阳虚 | 温煦不足 | 畏寒怕冷，手足不温 |
| 阴虚质 | 阴偏虚 | 阴液亏少 | 口干咽燥，手足心热 |
| 痰湿质 | 阴阳偏盛 | 痰湿凝聚 | 体形肥胖，苔腻滑 |
| 湿热质 | 阳偏盛 | 湿热内蕴 | 面垢油光，苔黄腻 |
| 血瘀质 | 阴阳偏颇 | 血行不畅 | 肤色晦暗，舌质紫暗 |
| 气郁质 | 阴阳偏颇 | 气机郁滞 | 情志不畅，胁胀叹息 |
| 特禀质 | 阴阳失衡 | 先天禀赋 | 过敏体质，易发疾病 |

    def __init__(self, transition_model):

    def counterfactual_comparison(self, current_state, interventions):
        """
        反事实比较：对比多种干预方案的效果
