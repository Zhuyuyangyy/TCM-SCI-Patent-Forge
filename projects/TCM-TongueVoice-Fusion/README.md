# 舌象-声纹-面色三模态体质识别系统

## 项目概述

本系统是中医体质三模态识别系统，融合舌象、声纹、面色三种模态进行中医体质分类。

### 体质分类
- 平和质
- 气虚质
- 阳虚质
- 阴虚质
- 痰湿质
- 湿热质
- 血瘀质
- 气郁质
- 特禀质

## 系统架构

### 核心模块

| 模块 | 文件 | 描述 |
|------|------|------|
| 舌象分析 | `tongue_analyzer.py` | 舌色RGB/苔色/裂纹/齿痕/舌形特征提取，输出8维特征 |
| 声纹分析 | `voice_analyzer.py` | F0/共振峰/LPC特征提取，输出8维特征 |
| 面色分析 | `face_analyzer.py` | 面色分区光泽度/微色差/血色，输出6维特征 |
| 多模态融合 | `multi_modal_fusion.py` | 早期融合(级联22维)→MLP→9种体质分类 |
| 可信评分 | `confidence_explainer.py` | 多模态冲突检测与解释 |
| 演示 | `demo.py` | 10+测试用例验证 |

### 特征维度
- 舌象特征: 8维
- 声纹特征: 8维
- 面色特征: 6维
- 融合特征: 22维

## 技术实现

### 纯NumPy实现
- 无需torch/tensorflow，轻量级
- 简化的CNN特征提取（NumPy实现）
- LPC/自相关法共振峰提取
- MLP反向传播实现

### 多模态融合策略
- **早期融合**: 级联三模态特征向量 (22维)
- **MLP分类器**: 22→64→32→16→9
- **加权投票**: 舌象35%/声纹25%/面色40%

## 可信评分机制

系统会对每个预测给出：
1. **综合可信评分**: 0-100%
2. **置信度等级**: 高/中/低/不可信
3. **冲突检测**: 检测模态间预测不一致
4. **异常模态识别**: 识别可能"说谎"的模态

## 中医理论基础

### 舌象诊断学
- 舌色反映气血阴阳盛衰
- 苔色反映病邪性质
- 裂纹/齿痕反映脏腑功能

### 声纹诊断学
- 基频(F0)反映声带张力
- 共振峰反映声道共鸣
- 抖动反映气息稳定性

### 面色诊断学
- 光泽度反映精气盛衰
- 微色差反映气血分布
- 血色反映血液循环
