# TCMAgent++: 中医多智能体会诊系统

> 基于多智能体协作的中医辨证论治智能系统

---

## 项目概述

TCMAgent++ 是一个基于多智能体协作架构的中医智能诊疗系统。系统模拟真实中医专家会诊流程，通过多个具有不同专业分工的智能体协同工作，实现复杂病症的联合诊断与会诊结论生成。

### 核心特性

| 特性 | 描述 |
|------|------|
| **异构智能体** | 5种不同专业分工的专家智能体 |
| **协作审议** | 对抗性假设消解机制 |
| **并行推理** | 多智能体同时分析患者信息 |
| **共识形成** | 结构化辩论与收敛机制 |

## 专家智能体

| 智能体 | 专业领域 | 核心职责 |
|--------|---------|---------|
| **TongueAgent** | 舌诊专家 | 分析舌象特征（舌色、苔质、苔色） |
| **HistoryAgent** | 问诊专家 | 收集病史、症状演变、生活习惯 |
| **LabAgent** | 检验专家 | 整合实验室检查指标 |
| **Deliberation** | 审议协调 | 主持辩论、引导共识 |
| **MultiAgentSystem** | 系统协调 | 整合各专家意见、生成最终报告 |

## 核心模块

### 1. base_agent.py - 基础智能体

所有专家智能体的基类，定义通用接口：

```python
class BaseAgent:
    def analyze(self, patient_info: dict) -> dict
    def propose_hypothesis(self, analysis: dict) -> Hypothesis
    def respond_to_challenge(self, challenge: str) -> Defense
```

### 2. 多智能体系统

```python
# 协调多智能体协作
multi_agent = MultiAgentSystem()
result = await multi_agent.consult(patient_info)
```

### 3. 对抗性辩论

辩论过程：
1. 随机选择两个持不同意见的专家
2. 攻击方提出质疑
3. 防守方进行辩护
4. 更新假设支持度
5. 重复直到收敛

## 快速开始

### 运行演示

```bash
python demo.py
```

### 自定义会诊

```python
from multi_agent_system import MultiAgentSystem

async def run_consultation():
    system = MultiAgentSystem()
    
    patient_info = {
        "symptoms": ["头痛", "眩晕", "耳鸣"],
        "tongue": {"color": "淡红", "coating": "薄白"},
        "pulse": "弦",
        "history": "高血压病史5年"
    }
    
    result = await system.consult(patient_info)
    
    print(f"主要诊断: {result.primary_diagnosis}")
    print(f"共识度: {result.consensus_score:.2%}")
```
