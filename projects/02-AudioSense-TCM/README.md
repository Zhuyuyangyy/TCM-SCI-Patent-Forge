# AudioSense-TCM: 语音韵律-脏腑功能映射系统

## 项目概述

AudioSense-TCM 是一个基于变分自编码器(VAE)的中医语音诊断系统，通过分析患者的语音特征来评估脏腑功能状态。该系统将现代声学分析与中医五行脏腑理论相结合，实现无创、便捷的脏腑功能评估。

## 核心模块

### 1. 语音特征提取器 (audio_extractor.py)

**功能**: 提取语音信号的声学特征。

**主要方法**:
- : 提取基频F0（自相关法）
- : 提取共振峰F1/F2/F3（LPC分析）
- : 提取语速
- : 提取能量熵
- : 提取全部特征

**特征说明**:
- F0 (基频): 反映音高，与发声器官振动频率相关
- 共振峰: 反映声道特性，与脏腑功能状态相关
- 语速: 反映气息平稳性和神志状态
- 能量熵: 反映声音稳定性和气息控制

### 3. 脏腑映射器 (zangfu_mapper.py)

**功能**: 将VAE输出映射为中医脏腑功能评估。

**五脏对应**:
- 心 (火): 主血脉，藏神
- 肝 (木): 主疏泄，藏魂
- 脾 (土): 主运化，藏意
- 肺 (金): 主气，藏魄
- 肾 (水): 藏精，主水

**状态分类**:
- 虚证: 概率 < 0.3
- 平: 0.3 ≤ 概率 ≤ 0.7
- 实证: 概率 > 0.7

## 学术价值

- 无创诊断：避免传统脉诊、舌诊的主观性
- 客观量化：将主观感受转化为可测量的声学参数
- 易于普及：智能手机即可采集语音样本
- SCI论文素材：跨学科创新点
- 发明专利：核心算法可申请专利保护

## 研究方向

1. **多模态融合**: 结合语音、面部、脉搏等多源信息
2. **时序建模**: 使用LSTM/Transformer建模语音时序特征
3. **个体适配**: 针对个体基线进行自适应校准
4. **临床验证**: 与中医专家诊断进行对照研究

## 技术亮点

1. **VAE潜空间**: 学习解耦的脏腑状态表示
2. **五行归类**: 语音特征与五行理论的对应关系
3. **综合报告**: 定量评估+定性解读+调理建议
