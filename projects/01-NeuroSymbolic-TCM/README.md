# NeuroSymbolic-TCM: 神经符号混合中医推理系统

## 项目概述

NeuroSymbolic-TCM 是一个结合神经网络学习和符号逻辑推理的中医智能辨证论治系统。该系统将传统的五行生克理论与现代深度学习技术相结合，实现可解释、可验证的中医证候鉴别和方剂推荐。

### 3. 五行验证层 (verification_layer.py)

**功能**: 验证证候转移和处方配伍是否符合五行生克规则。

**核心方法**:
- : 验证证候转移
- : 验证处方配伍
- : 提供修正建议

## 研究方向

1. **神经符号混合推理**: 结合神经网络的学习能力和符号逻辑的可解释性
2. **五行约束的硬编码**: 在推理过程中强制执行五行生克规则
3. **君臣佐使注意力**: 将传统药性理论嵌入现代Transformer架构
