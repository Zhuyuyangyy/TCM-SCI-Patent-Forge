# Target 002 专利权利要求书 — 脉象PINN物理神经网络

## 独立权利要求

**权利要求1.** 一种基于物理信息神经网络的中医脉象动力学仿真方法，其特征在于，包括以下步骤：

S1. 将桡动脉寸关尺三部脉搏波传播过程建模为一维流体动力学偏微分方程：
$$\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2} - \delta \frac{\partial u}{\partial t} + f(x,t)$$
其中u(x,t)为脉波位移，c为波速，δ为阻尼系数，f(x,t)为心脏驱动力；

S2. 构建全连接神经网络，以空间坐标x和时间t为输入，以脉波位移u(x,t)为输出；

S3. 通过自动微分计算网络输出对输入的一阶和二阶偏导数，将所述偏微分方程的残差作为物理约束损失项L_pde嵌入训练目标；

S4. 设计复合损失函数L = L_data + λ₁·L_pde + λ₂·L_bc + λ₃·L_ic，其中L_data为实测脉象数据拟合损失，L_bc为边界条件损失，L_ic为初始条件损失；

S5. 将波速c和阻尼系数δ作为可学习参数，使网络在拟合数据的同时自动辨识脉象的血流动力学特征参数。

## 从属权利要求

**权利要求2.** 根据权利要求1所述的方法，其特征在于，所述步骤S2中的神经网络包含6层全连接层，每层128个神经元，采用Tanh激活函数；在第3层设置跳跃连接以增强梯度传播。

**权利要求3.** 根据权利要求1所述的方法，其特征在于，所述步骤S1中的心脏驱动力f(x,t)由独立的子网络建模，以(x,t)为输入输出驱动力值，实现心脏搏动波形的自适应学习。

**权利要求4.** 根据权利要求1所述的方法，其特征在于，在所述物理信息神经网络之上增设脉象分类头，以寸关尺三部的脉波时间序列为输入特征，输出16类标准脉象的分类概率。

**权利要求5.** 一种基于物理信息神经网络的中医脉象仿真系统，其特征在于，包括：脉象信号采集模块、偏微分方程物理约束模块、神经网络训练模块、血流动力学参数辨识模块和脉象分类模块。

## 里程碑意义 (Agent-Innovation)

### 数据驱动 + 经典力学约束 = 跨越中西医鸿沟

**西医视角**: 脉搏波是血管壁在心脏驱动下的机械振动，可用Navier-Stokes方程描述。
**中医视角**: 脉象是脏腑气血盛衰的外在表现，分浮沉迟数滑涩弦紧等28种。

**本方案的桥梁作用**:
- 物理参数c(波速) ↔ 血管弹性 ↔ 中医"弦脉"(血管紧张度高→c大)
- 物理参数δ(阻尼) ↔ 血液粘度 ↔ 中医"涩脉"(血瘀→δ大)
- 心脏驱动力f(x,t) ↔ 心脏功能 ↔ 中医"虚脉"(心气虚→f弱)

这是首次将中医脉象的主观描述与血流动力学的客观参数建立定量映射关系。
