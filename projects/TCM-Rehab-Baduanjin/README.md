# 八段锦动作识别与纠偏系统

八段锦动作识别与纠偏系统 - 基于NumPy实现的姿态估计、偏差检测、质量评分和康复处方推荐。

## 项目概述

本系统针对中医传统健身气功"八段锦"开发了一套完整的动作识别与智能纠偏解决方案。

### 核心功能

1. **姿态估计** (`pose_estimator.py`) - 从骨骼点数据识别八段锦8个动作阶段
2. **标准模板库** (`movement_db.py`) - 存储每个动作的关节点角度标准值
3. **偏差检测** (`deviation_detector.py`) - 实时计算偏差并输出纠偏指令
4. **质量评分** (`score_evaluator.py`) - 100分制评分(偏差/稳定性/节奏感)
5. **康复处方** (`rehab_prescriber.py`) - 根据体质和评分推荐运动方案

### 八段锦八式

| 序号 | 动作名称 | 功效 |
|------|----------|------|
| 1 | 双手托天理三焦 | 调理气机，伸展腰背 |

| 8 | 收势 | 整理气息，恢复平静 |

## 技术架构

### 骨骼点模型

系统使用15个关键骨骼点:

```
骨骼点索引:
0: nose (鼻)
1: neck (颈)
2: r_shoulder (右肩)
3: r_elbow (右肘)
4: r_wrist (右腕)
5: l_shoulder (左肩)
6: l_elbow (左肘)
7: l_wrist (左腕)
8: r_hip (右髋)
9: r_knee (右膝)
10: r_ankle (右踝)
11: l_hip (左髋)
12: l_knee (左膝)
13: l_ankle (左踝)
14: spine_mid (脊柱中点)
```

### 评分维度

- **偏差幅度** (50%): 当前姿态与标准模板的偏差程度
- **稳定性** (30%): 动作过程中的身体稳定性
- **节奏感** (20%): 动作完成的节奏一致性

## 中医体质分类

系统支持9种中医体质类型:

- 气虚质、阳虚质、阴虚质
- 痰湿质、湿热质、血瘀质
- 气郁质、特禀质、平和质

不同体质对应不同的运动强度和禁忌动作。

## 算法说明

### 角度计算

使用余弦定理计算三关节角度:
```
cos(θ) = (v1·v2) / (|v1||v2|)
```

### 偏差检测

计算当前特征值与标准范围的中心点偏差,超过阈值时生成纠偏指令。

### 评分公式

```
总分 = 偏差得分×0.5 + 稳定性得分×0.3 + 节奏感得分×0.2
```
