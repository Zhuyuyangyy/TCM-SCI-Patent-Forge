# TCM-Acupuncture-Robot E01

## 项目概述

机械臂推拿力度-穴位-形变闭环控制系统 (E01)

实现中医推拿的自动化控制，通过PID闭环控制维持稳定的压力输出，结合胡克定律弹性模型计算组织形变，并配备完善的安全监控机制。

## 系统架构

```
TCM-Acupuncture-Robot/
├── acupoint_locator.py      # 20+穴位坐标数据库
├── pressure_controller.py  # PID闭环压力控制器
├── tissue_deformation.py    # 胡克定律弹性模型
├── safety_monitor.py        # 风险区域避让与安全监控
├── demo.py                  # 完整演示程序
├── README.md
└── requirements.txt
```

## 核心模块

### 1. acupoint_locator.py - 穴位坐标库

包含22个穴位坐标，支持：
- 足阳明胃经 (足三里、上巨虚、下巨虚、丰隆、梁丘、犊鼻)
- 足太阳膀胱经 (肾俞、胃俞、委中、承山)
- 足太阴脾经 (三阴交、阴陵泉、血海)
- 足少阴肾经 (涌泉、太溪、照海)
- 足少阳胆经 (阳陵泉、环跳、风市)
- 任脉 (关元、中脘)
- 经外奇穴 (胆囊穴、阑尾穴)

每个穴位包含：坐标(x,y,z)、安全深度范围、风险等级、禁忌症

### 2. pressure_controller.py - PID控制器

- 基础PID控制器
- 自适应PID控制器 (根据组织刚度调整参数)
- Ziegler-Nichols调优支持
- 控制周期: 10ms
- 输出: 速度指令 (N/s)

### 3. tissue_deformation.py - 组织形变模型

基于胡克定律: `σ = E × ε` / `F = k × Δx`

- 多层组织模型 (皮肤→脂肪→肌肉→骨膜)
- 各层弹性模量 (MPa)
- 粘弹性模型 (蠕变效应)
- 安全阈值判断

### 4. safety_monitor.py - 安全监控

- 风险区域数据库 (神经区、血管区、关节腔、脏器等)
- 实时位置安全检查
- 轨迹安全检查
- 避让建议

### 5. demo.py - 演示流程

```
选择足三里 → 机械臂定位 → 12N PID控制 → 形变计算 → 安全报告
```
