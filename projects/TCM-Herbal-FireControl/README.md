# TCM-Herbal-FireControl
## H05中药炮制火候智能判定系统

### 项目概述

TCM-Herbal-FireControl 是一个中药炮制火候智能判定系统，通过模拟温度曲线、神经网络判定和颜色纹理分析，实现对中药材炮制过程中火候控制的智能化判定与质量评估。

### 核心功能

1. **herb_database.py** - 中药材炮制参数数据库
   - 收录20+种常用中药材的炮制参数
   - 包含温度范围、持续时间、火力等级等关键参数
   - 记录质量标志物和颜色纹理变化特征

2. **fire_sensor_sim.py** - 炮制温度传感器模拟器
   - 生成标准温度曲线
   - 模拟真实炮制过程中的温度波动
   - 支持多阶段温度曲线定制

3. **fire_judge_model.py** - 火候智能判定模型
   - 混合判定系统（规则+神经网络）
   - 实时温度曲线分析
   - 多阶段火候评估与建议生成

4. **color_texture_analyzer.py** - 颜色纹理分析器
   - 炮制前后颜色变化建模（RGB/HSV/Lab色彩空间）
   - 纹理特征提取与分析
   - 质量指标综合评定

5. **demo.py** - 完整演示系统
   - 输入药材和目标火候
   - 生成温度曲线
   - 火候判定与质量评估
   - 生成综合报告

### 火候判定等级

- **qualified** (优秀): 综合得分 ≥85，温度控制稳定
- **acceptable** (合格): 综合得分 ≥70，存在轻微偏差
- **overheat** (过热): 温度超过上限时间过长
- **insufficient** (不足): 保温时间不足
- **failed** (失败): 判定不通过

### 质量评估维度

1. **火候控制** (权重70%)
   - 温度偏差
   - 保温时间达标率
   - 温度波动稳定性
   - 各阶段表现

2. **外观质量** (权重30%)
   - 颜色变化 (ΔE色差)
   - 纹理变化 (粗糙度、光泽度)
