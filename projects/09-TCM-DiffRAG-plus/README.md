# TCM-DiffRAG++: 扩散检索增强生成系统

> 基于扩散模型与知识图谱的中医个性化诊断检索增强生成系统

---

## 项目概述

TCM-DiffRAG++ 是一个将扩散模型（Diffusion Model）与知识图谱检索增强生成（RAG）深度融合的中医智能诊断系统。系统通过患者个性化信息引导扩散过程，实现精准、可解释的中医辨证论治辅助决策。

### 核心特性

| 特性 | 描述 |
|------|------|
| **知识图谱索引** | 实体、关系、子图多层次检索 |
| **扩散生成** | 条件扩散模型生成诊断候选 |
| **个性化引导** | 根据体质类型动态调整检索权重 |
| **禁忌过滤** | 自动过滤患者禁忌药物/治疗 |
| **路径发现** | 支持实体间多跳推理路径 |

## 快速开始

### 运行演示

```bash
python demo.py
```

### 自定义诊断

```python
from kg_index import KGIndex
from diff_rag import DiffRAG

# 初始化
kg_index = KGIndex("path/to/kg")
diff_rag = DiffRAG(kg_index)

# 患者信息
patient = {
    "symptoms": ["头痛", "眩晕", "胁胀"],
    "tongue": {"color": "淡红", "coating": "薄白"},
    "pulse": "弦",
    "体质": "气郁质"
}

# 个性化检索与生成
context = diff_rag.retrieve_with_personalization(patient["symptoms"], patient["体质"])
result = diff_rag.generate_diagnosis(patient, context)

print(f"诊断: {result.diagnosis}")
print(f"方案: {result.prescription}")
print(f"依据: {result.evidence}")
```
