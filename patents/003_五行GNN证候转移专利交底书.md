# 专利技术交底书

## 一、发明名称

一种融合五行生克约束的中医证候转移概率建模方法及系统

## 二、技术领域

本发明属于中医信息化与人工智能交叉领域，具体涉及一种将中医五行学说与图神经网络相结合，用于建模证候之间转移概率、预测病机演变的计算机辅助诊断方法及系统。

## 三、背景技术（现有技术的问题）

中医证候是疾病过程中整体病变的综合反应，反映了人体正气与致病因素相互抗争的状态。证候之间存在发生、发展和转化的动态关系，把握这种关系对于疾病预防、治疗决策和预后判断具有重要意义。现有技术在证候建模方面存在以下突出问题：

第一，病机演化难以量化。中医病机演化理论认为证候之间存在因果转化关系，但这种关系主要停留在文字描述层面，缺乏可计算的数学模型，无法进行定量预测和仿真。

第二，五行学说缺乏形式化表示。"五行相生相克"是中医核心理论，但现有计算机模型难以准确表达这种带有约束性质的复杂关系，生、克、乘、悔等多种作用混在一起，难以区分和计算。

第三，证候转移概率无法估计。临床上无法预判某一证候向其他证候转化的可能性大小，导致治疗策略缺乏前瞻性，容易错过最佳干预时机。

第四，个体差异难以考量。不同患者的体质、年龄、基础疾病等因素影响证候演变路径，现有模型多关注群体共性规律，忽视个体特异性。

第五，领域知识与数据融合困难。中医专家经验以案例和医论形式存在，图谱结构化知识以规则形式存在，如何与大规模临床数据融合建模仍是难题。

综上所述，中医证候动态演变研究缺乏有效的计算工具和模型支撑，亟需一种能够融合领域知识与数据驱动、同时考虑五行约束的证候转移概率建模方法。

## 四、发明内容（核心创新点，详细描述）

本发明提供一种融合五行生克约束的中医证候转移概率图神经网络建模方法，其核心创新点包括以下几个方面：

**创新点一：证候图节点的构建与属性表示**

本发明将中医证候建模为图结构中的节点，建立证候知识图谱。节点定义采用多层次属性表示，包括基础属性、症状属性和治疗属性三类。

基础属性包含证候名称（五行归类：肝、心、脾、肺、肾）、证候定义（症状集合）、诊断标准（主要指标和次要指标）等静态信息。

症状属性为每个证候节点的症状向量表示，维度与症状字典规模相同（建议100-200维），采用one-hot或TF-IDF编码。该向量反映了证候的诊断特征分布。

治疗属性包括对应治法（汗、吐、下、和、温、清、消、补）、推荐方剂（方剂编码列表）、针灸穴位（穴位编码集合）等治疗相关知识。

节点初始化采用知识图谱嵌入方法（TransE或RotatE），将结构化知识编码为低维稠密向量（建议维度64-128），作为图神经网络的初始节点表示。

**创新点二：五行相生关系的有向边建模**

本发明将五行相生关系建模为有向加权边。五行相生顺序为：木生火、火生土、土生金、金生水、水生木，对应中医藏象：肝→心→脾→肺→肾→肝。

相生边定义为有向边，边的方向表示证候转化的可能方向。每条相生边赋予可学习的转移强度权重，初始值根据临床统计确定。例如：肝火炽盛（肝）向心火亢盛（心）转移的初始概率可设为0.35，反映临床观察到的关联强度。

相生关系的传播规则为：当源节点状态增强时，通过相生边传递正向激活，目的地节点状态也倾向于增强。数学表示为：
P(n_j | n_i) = σ(W_s · h_i + b_s)
其中n_i为源节点，n_j为目标节点，h_i为节点状态向量，W_s和b_s为可学习参数，σ为sigmoid函数。

**创新点三：五行相克关系的抑制边建模**

本发明将五行相克关系建模为抑制边。五行相克顺序为：木克土、土克水、水克火、火克金、金克木，对应中医：肝克脾、脾克肾、肾克心、心克肺、肺克肝。

相克边同样定义为有向边，但与相生边不同，相克边传递负向抑制信号。当源节点状态增强时，通过相克边抑制目标节点。数学表示为：
I(n_j | n_i) = -σ(W_k · h_i + b_k)
其中W_k和b_k为相克边的可学习参数，负号表示抑制作用。

本发明区分"克"、"乘"、"悔"三种不同程度的抑制作用。正常克制的强度系数设为1.0，乘（克制过度）系数设为1.5，悔（反克为虐）系数设为0.8。不同强度对应不同的边权重初始值。

**创新点四：基于注意力机制的证候转移概率预测**

本发明采用图注意力网络（GAT）架构实现证候转移概率的预测。GAT层计算公式为：
α_ij = softmax_j(LeakyReLU(a^T · [W·h_i || W·h_j]))
h'_i = σ(Σ_j α_ij · W·h_j)

其中α_ij为节点i到节点j的注意力权重，||表示向量拼接，a为注意力参数向量，W为线性变换矩阵，σ为激活函数。

针对五行约束的特殊性，本发明设计了约束注意力机制。在计算注意力权重时，引入五行约束掩码：若边(i,j)不属于五行的生或克关系，则将注意力权重强制设为0；若属于相生关系，则注意力通过相生通道计算；若属于相克关系，则通过相克通道计算。最终注意力为相生注意力和相克注意力的融合：
α_ij = λ_s · α_ij^s + λ_k · α_ij^k
其中λ_s和λ_k为融合系数，满足λ_s + λ_k = 1。

转移概率预测输出层采用多分类Softmax，输出当前证候向各目标证候的转移概率分布。损失函数包含两部分：标准分类交叉熵L_ce和五行约束损失L_constraint。约束损失定义为：
L_constraint = Σ_{(i,j)∈E_valid} |y_ij - ŷ_ij|
即对每条有效边，约束预测的转移概率ŷ_ij与中医理论预期的y_ij之间的差异。五行约束损失权重设为0.3，确保模型在满足约束的前提下优化预测性能。

## 六、具体实施方式

**实施例一：基于历史医案的证候转移模型训练**

该实施例适用于利用大规模中医医案数据训练证候转移预测模型，具体步骤如下：

步骤1：数据收集与预处理。从电子病历系统或公开数据集（如中医医案数据库）获取标注完整的门诊/住院病历。纳入标准为：具有明确证候诊断、记录症状体征、有治疗过程和转归记录。数据清洗包括：统一证候命名（参考《中医证候规范》）、症状标准化（参考《中医症状界定标准》）、治疗方案归一化（方剂和穴位名称统一编码）。

步骤2：证候图谱构建。建立包含不少于50种常见证候节点的图谱，每个节点包含基础属性、症状向量和治疗属性。节点初始化采用预训练的TransE嵌入，维度设为64。边集合包含所有相生边（共5条）和所有相克边（共5条），边权重根据专家经验初步赋值。

步骤3：GNN模型训练。模型包含3层GAT，隐藏层维度分别为64、64、32，注意力头数设为4。训练采用Adam优化器，学习率0.001，批量大小32，共训练200个epoch。损失函数权重λ_ce=0.7，λ_constraint=0.3。

步骤4：模型验证。采用5折交叉验证评估模型性能，主要指标包括证候转移预测准确率（Top-1和Top-3）、五行约束满足率（计算所有预测结果中符合五行生克规则的占比）、以及与随机基线模型的对比提升。

步骤5：模型部署。将训练好的模型参数导出为标准格式，部署至预测服务器。提供API接口，输入当前证候状态和患者特征向量，输出转移概率分布和干预建议。

该实施例的典型参数范围为：训练样本量5000-20000例，证候类别数50-100种，症状特征维度100-200维，TransE嵌入维度64，GAT层数3层，隐藏维度64-64-32，注意力头数4，训练epoch 200个。

**实施例二：个体化证候转移预测与干预建议系统**

该实施例适用于面向个体的临床辅助决策支持，具体步骤如下：

步骤1：患者信息采集。通过问诊系统采集患者当前症状和体征，包括主诉、现病史、既往史、舌象、脉象等信息。舌脉信息可由本项目其他专利系统（舌象3D-NeRF系统、脉象PINN系统）自动提取。

步骤2：当前证候推断。将患者症状向量输入证候分类器，输出当前证候的推断概率分布。分类器基于训练好的GNN编码器实现，保持参数冻结，仅更新适配层。适配层采用2层全连接网络，输出维度与证候类别数相同。

步骤3：证候转移预测。将当前证候状态向量输入GNN解码器，输出向各目标证候的转移概率。根据概率大小排序，取Top-5作为最可能的演变方向。

步骤4：五行约束校验。检查预测结果是否符合五行约束：若预测转移方向不符合任何生或克关系，标记为"异常转移"，需专家复核；若存在多条符合约束的路径，按概率大小排序。

步骤5：干预建议生成。根据预测结果和中医治疗原则，生成干预建议。若预测显示证候向坏的方向转化（如实证加重或实证转虚证），建议加强祛邪力度或补充扶正药物；若预测显示证候向好的方向转化，可维持当前治疗方案。

步骤6：反馈学习。将本次诊断结果和治疗转归记录加入训练数据，定期（或达到100例新增时）对模型进行增量训练，更新模型参数以适应本医疗机构患者群体特征。

该实施例的特有参数为：症状输入维度150维（标准问诊量表），当前证候推断采用Top-1准确率评估（目标>80%），转移预测Top-3准确率目标>70%，五行约束满足率目标>95%，干预建议生成延迟<1秒。

## 七、技术优势

本发明相对于现有技术具有以下显著优势：

**理论严谨性**：完整保留了五行相生相克理论的约束关系，确保预测结果符合中医基本理论框架，避免生成违背中医原则的预测。

**可解释性强**：五行约束以可视化方式展示，便于中医师理解和审核模型决策过程，提高临床应用的可接受度。

**预测与干预一体化**：不仅预测证候转移方向，还根据预测结果给出相应的干预建议，实现"治未病"的主动健康管理。

**融合领域知识与数据**：知识图谱嵌入和约束损失函数将专家经验显式编码，同时通过数据训练不断优化参数，实现知识与数据的协同提升。

**个体化适配**：支持根据个体特征（体质、年龄、基础疾病等）调整预测模型，提高预测的个体相关性。

**持续学习能力**：支持增量训练和模型更新，可不断吸收新病例和临床经验，保持模型的时效性和准确性。

## 八、可实验验证的指标（关键！必须列出明确的评价指标）

本发明以下列指标作为技术方案有效性的验证标准：

**证候预测准确率**：以最终随访确认的证候诊断为金标准，评估模型预测当前证候和转移方向的能力。合格标准：当前证候Top-1准确率>78%，转移预测Top-3准确率>65%。

**五行约束满足率**：计算模型所有预测结果中符合五行生克规则的占比。合格标准：满足率>95%，即超过95%的预测转移方向在五行理论中是允许的。

**转移概率校准度**：比较预测的转移概率值与实际观测频率的一致性，采用Brier评分评估。合格标准：Brier评分<0.15，表明概率估计具有较好的校准性。

**Top-K预测覆盖率**：统计真实转移方向出现在Top-K预测中的比例。合格标准：Top-3覆盖率>75%，Top-5覆盖率>85%。

**干预建议有效性**：在有对照的临床研究中，比较基于本系统建议的干预组与标准治疗组的预后差异。合格标准：干预组症状改善率比对照组提升≥10%，或达到相同效果的治疗时间缩短≥15%。

**个体化适配提升率**：对比通用模型与个体化适配后模型在同一患者上的预测表现，评估适配的增益效果。合格标准：个体化适配后准确率提升≥8%。

**增量训练收敛性**：评估新增样本对模型参数的影响程度。合格标准：增量训练后，验证集准确率保持稳定（变化<2%），不发生灾难性遗忘。

**计算效率**：单次预测（从输入到输出）的平均延迟。合格标准：延迟<1秒，满足临床实时性要求。

上述指标将通过回顾性研究和前瞻性临床试验进行验证。回顾性研究利用历史医案数据集（不少于5000例）评估模型性能。前瞻性临床试验在合作中医医疗机构开展，采用随机对照设计，纳入标准为符合中医证候诊断标准的门诊患者，样本量根据主要结局指标计算（预计每组不少于60例）。统计方法包括描述性分析、组间比较（t检验或卡方检验）以及生存分析（Cox回归），P<0.05为统计学显著。
