# 专利技术交底书：强化学习针灸力度控制系统

## 一、发明名称

一种基于SARSA算法和示教学习的针灸刺入力度智能控制方法

## 二、技术领域

本发明属于中医针灸自动化技术领域，具体涉及一种通过强化学习算法实现针灸操作过程中刺入力度和深度实时智能控制的方法及系统，适用于针灸机器人、辅助训练设备和智能针灸仪等产品。

## 三、背景技术

针灸作为中医最具代表性的外治法之一，在临床应用中具有悠久的历史和显著的疗效。针灸操作要求医师精准控制针具的刺入角度、速度和力度，将针体送达适当的深度和穴位，以达到"得气"的治疗状态。针灸手法讲究"轻巧稳准"，对操作者的技术和经验有较高要求。

传统针灸技能的传承主要依靠师徒间的口传心授和大量临床实践，学习周期长、技术门槛高。随着医疗机器人和自动化技术的发展，针灸操作的机械化和智能化成为可能。然而，针灸操作具有高度的非线性特征：不同患者的皮肤硬度、肌肉紧张度和穴位深度存在显著差异，针具在刺入过程中会遇到动态变化的阻力，简单的位置控制或速度控制难以保证稳定的刺入质量。

现有的针灸辅助设备主要采用位置控制策略，即预先设定针具的刺入深度，通过电机驱动使针具到达指定位置。这种方法忽略了刺入过程中阻力的动态变化，当患者体质或穴位特征与预设模型不符时，可能导致刺入过浅（疗效不足）或刺入过深（潜在安全风险）。部分研究尝试引入力反馈控制，但传统PID控制器的参数调试困难，面对针灸过程中的复杂非线性特性难以保持良好的鲁棒性。

强化学习（Reinforcement Learning）为解决这类问题提供了新的思路。强化学习通过智能体与环境的交互学习最优策略，能够在非线性、不确定的系统中实现自适应控制。然而，直接应用强化学习进行针灸控制面临样本效率低下和训练过程不安全的问题：针灸操作需要精准的力度控制，从零开始学习的强化学习过程可能产生危险的刺入动作。

针对上述挑战，本发明提出一种基于SARSA算法和示教学习（Demonstration Learning）的针灸刺入力度智能控制方法，通过模仿人类针灸医师的示教轨迹加速策略学习，确保训练过程的安全性和收敛后的控制精度。

## 四、发明内容

本发明提出一种基于SARSA算法和示教学习的针灸刺入力度智能控制方法，其核心创新在于将人类针灸专家的示教轨迹作为先验知识融入强化学习过程，结合力反馈实现刺入力度的实时自适应控制。

### 4.1 针灸操作的状态空间与动作空间定义

本发明首先定义了针灸刺入操作的状态空间和动作空间，为强化学习建模奠定基础。

状态空间S包含以下维度：当前位置z（针尖相对于皮肤表面的距离，单位mm）、当前速度v（针具刺入速度，单位mm/s）、当前力度f（针具受到的阻力，单位N）、目标深度d_target（预设的刺入目标深度，单位mm）、患者体质参数p（包含皮肤硬度指数、肌肉紧张度指数、穴位特征参数等）。状态向量表示为：

s_t = [z_t, v_t, f_t, d_target, p_1, p_2, ..., p_n]

动作空间A定义为刺入速度的调整量Δv，即智能体输出的是速度变化指令而非直接的位置指令。这种设计符合针灸操作中"徐入"的手法原则，便于控制器实现平滑的刺入过程。动作空间约束为Δv ∈ [-v_max, v_max]，其中v_max为最大速度调整量。

奖励函数r(s, a, s')的设计综合考虑三个方面：任务奖励（是否达到目标深度）、安全奖励（刺入力度是否在安全范围内）和效率奖励（刺入过程是否平稳流畅）。综合奖励函数为：

r(s, a, s') = w_1 × r_task + w_2 × r_safety + w_3 × r_efficiency

其中各子奖励的定义如下：

任务奖励：r_task = 1 if |z_t - d_target| < ε else 0（ε为目标误差阈值）

安全奖励：r_safety = 1 if f_t < f_max else -1（f_max为安全力度上限）

效率奖励：r_efficiency = -|Δv| / v_max（鼓励平稳动作，惩罚剧烈调整）

### 4.2 SARSA算法设计

SARSA（State-Action-Reward-State-Action）是一种基于策略的时序差分强化学习算法，与Q-Learning相比具有更高的策略稳定性和更低的估值偏差。本发明选择SARSA作为核心学习算法，原因在于针灸控制对安全性要求极高，SARSA的在线策略特性能够更好地保证学习过程中的安全性。

SARSA算法的核心是动作-价值函数Q(s, a)的更新：

Q(s_t, a_t) ← Q(s_t, a_t) + α[r_t + γQ(s_{t+1}, a_{t+1}) - Q(s_t, a_t)]

其中α为学习率，γ为折扣因子。ε-贪心策略用于平衡探索与利用：

a_t = argmax_a Q(s_t, a)  with probability 1-ε
a_t = random(a)          with probability ε

为适应针灸控制的连续状态空间，本发明采用函数逼近方法表示Q函数。选用深度神经网络（Deep Q-Network）作为函数逼近器，网络结构包含3层全连接层，隐藏单元数分别为128、64、32，激活函数为ReLU。网络的输入为状态向量s，输出为各动作的Q值估计。

### 4.3 示教学习加速策略

从零开始训练强化学习智能体需要大量的交互样本，这在针灸控制场景中既耗时又危险。本发明引入示教学习（Demonstration Learning）机制，利用人类针灸专家的示教轨迹加速策略学习。

示教数据采集过程如下：邀请10位具有10年以上临床经验的主治中医师，使用配备力传感器的针灸训练设备完成200个穴位的标准刺入操作。设备记录每次操作的完整状态-动作轨迹作为示教数据。

示教学习采用行为克隆（Behavioral Cloning）和逆向强化学习（Inverse RL）相结合的两阶段方法：

第一阶段为行为克隆，训练一个示教策略网络π_demo(s)，使其在示教状态下的动作分布与专家示教动作分布相近。行为克隆的损失函数为：

L_BC = E_{s~D_demo}[-log π(a_demo|s)]

第二阶段为逆向强化学习，从示教数据中推断奖励函数R(s, a)，然后用推断的奖励函数训练SARSA智能体。这一阶段使用最大熵逆向强化学习（Maximum Entropy IRL）方法：

R* = argmax_R E_{π_demo}[R] - log Z(R)

其中Z(R)为配分函数。通过交替优化R和π，逐步逼近专家的隐式奖励函数。

最终的控制策略由示教学习的初始策略和SARSA微调后的策略加权融合得到：

π_final = β × π_irl + (1-β) × π_sarsa

其中融合系数β在训练初期接近1（依赖示教知识），在训练后期逐渐趋近0（依赖自学习知识）。

### 4.4 实时刺入深度控制

将训练好的策略模型部署为实时控制器是本发明的最终目标。控制器采用预测-控制循环结构：

首先，控制器读取当前状态s_t，包括位置传感器、速度传感器和力传感器的读数。

然后，控制器将s_t输入策略网络，计算动作a_t = π(s_t)。动作a_t为刺入速度调整量。

接着，控制器输出速度指令给针具驱动电机，电机驱动针具按指令调整刺入速度。

最后，控制器等待下一个控制周期（控制频率为100Hz），重复上述过程。

整个控制过程在10ms内完成，满足实时性要求。当检测到力度超出安全阈值时，控制器立即触发安全停止机制，暂停针具运动并报警。

## 五、具体实施方式

### 5.1 系统硬件架构

针灸力度控制系统由机械执行机构、传感系统和计算控制单元三部分组成。

机械执行机构包括高精度线性电机（行程100mm，推力50N，定位精度0.01mm）、针具夹持器和限位保护装置。线性电机选用音圈电机方案，响应速度快，输出力控特性好。针具夹持器采用快换式设计，支持不同规格针灸针的快速更换。

传感系统包括位置传感器（光栅尺，分辨率1μm）、速度传感器（编码器，分辨率0.1mm/s）和力传感器（应变片式力传感器，量程50N，精度0.1N）。传感器采样频率统一为1kHz，通过信号调理电路进行滤波和放大。

计算控制单元采用嵌入式工业控制计算机，配备Intel Core i7处理器和NVIDIA Jetson边缘计算模块。策略网络部署在Jetson模块上，利用其GPU加速能力实现实时推理。控制周期设定为10ms，确保系统响应的实时性。

### 5.2 策略网络训练流程

策略网络的训练分为离线训练和在线微调两个阶段。

离线训练阶段使用预采集的示教数据和模拟环境进行。团队构建了一个基于物理仿真的针灸模拟环境，模拟不同体质患者的皮肤、肌肉和组织阻力特性。模拟环境能够产生无限量的训练样本，解决真实示教数据不足的问题。

离线训练采用两阶段方法：第一阶段行为克隆训练100个epoch，第二阶段IRL-SARSA训练200个epoch。训练过程中每20个epoch在验证集上评估策略性能，保留最优模型。

在线微调阶段在真实针灸训练设备上进行，使用真实患者的针灸手感数据微调策略网络。在线微调采用保守策略：仅在患者明确授权的前提下进行，且微调范围限制在离线训练策略的邻域内，避免策略剧烈跳变。

### 5.3 实验验证

为验证本发明方法的有效性，团队设计了模拟实验和真人实验两个层次的验证方案。

模拟实验在虚拟患者模型上进行。虚拟患者模型基于真实患者的超声影像数据构建，包含皮肤层、浅筋膜层、深筋膜层和肌肉层的力学参数。实验选取20个不同体质特征的虚拟患者，测试系统在各种体质条件下的刺入精度。

实验结果表明，本发明提出的SARSA+Demonstration方法在不同虚拟患者上的平均刺入误差为1.3mm，误差<5%的目标要求。相较于基线方法（纯PID控制：误差4.2mm，纯Q-Learning：误差2.8mm），本方法在精度和鲁棒性上均有显著提升。

真人实验在针灸训练志愿者身上进行（已获伦理委员会批准）。实验选取足三里、关元、合谷等10个常用穴位，由系统控制针具完成刺入操作，邀请资深中医师评估刺入质量和得气感。评估结果显示，92%的试验达到"合格"以上标准，78%达到"良好"标准。

消融实验表明，示教学习对刺入误差的降低贡献约为58%，SARSA算法的贡献约为32%，力反馈机制的贡献约为10%。这一结果表明，示教学习是提升系统性能的关键因素，有效解决了从零开始训练样本效率低下的问题。

## 六、有益效果

本发明提出的基于SARSA算法和示教学习的针灸刺入力度智能控制方法，实现了针灸操作过程中刺入力度的实时自适应控制。示教学习机制充分利用人类专家的知识经验，大幅缩短了强化学习的训练周期，提高了训练过程的安全性。SARSA算法的在线策略特性保证了控制策略在复杂非线性环境中的稳定性。

实验验证表明，该方法的刺入误差控制在5%以内，满足临床应用的基本要求。系统的推广应用有望降低针灸操作的技术门槛，缓解优质针灸医师资源不足的问题，为针灸教学的标准化和规范化提供技术支撑。

## 七、权利要求书

1. 一种基于强化学习的针灸刺入力度控制方法，其特征在于，包括以下步骤：
   - 定义针灸操作的状态空间和动作空间，状态包含位置、速度、力度和目标深度；
   - 构建基于SARSA算法的动作-价值函数，使用深度神经网络逼近Q函数；
   - 通过示教学习采集人类专家的示教轨迹，利用行为克隆和逆向强化学习初始化策略网络；
   - 部署训练好的策略网络为实时控制器，实现刺入力度的自适应控制。

2. 根据权利要求1所述的方法，其特征在于，所述示教学习包括行为克隆阶段和逆向强化学习阶段，两阶段训练结果加权融合得到初始策略。

3. 根据权利要求1所述的方法，其特征在于，所述动作空间定义为刺入速度调整量，采用平滑的速度控制实现平稳刺入。

4. 根据权利要求1所述的方法，其特征在于，还包括力反馈安全机制，当检测到力度超出安全阈值时立即触发安全停止。

5. 一种实现权利要求1-4任一项所述方法的系统，包括机械执行机构、力传感系统和计算控制单元。
