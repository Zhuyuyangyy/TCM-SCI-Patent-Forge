# 专利技术交底书

## 一、发明名称

一种基于物理-神经混合建模的脉象信号客观化分析方法及系统

## 二、技术领域

本发明属于中医诊断工程与技术领域，具体涉及一种将动脉血管弹性力学偏微分方程模型与物理约束神经网络相结合，用于客观化采集分析脉象信号、实现证候智能分类的计算机辅助诊断方法及系统。

## 三、背景技术（现有技术的问题）

脉诊是中医四诊的重要组成部分，通过触诊寸口脉的位、数、形、势等特征判断人体脏腑功能状态和疾病性质。传统脉诊依赖医师的手指触觉和主观经验，存在以下突出问题：

第一，主观性强、可重复性差。不同医师对同一脉象的指感描述存在差异，同一医师在不同时间的判断也可能不一致，导致诊断结果缺乏客观依据，难以形成统一的金标准。

第二，信号采集困难。脉搏信号具有频率低（0.5-10Hz）、幅度小（压力变化约0.1-10kPa）、易受干扰等特点，对传感器灵敏度和采样精度要求高，现有压力传感器在长时间采集过程中稳定性不足。

第三，机理不清晰。脉波的产生涉及心脏泵血、动脉血管弹性、末梢阻力等多重生理因素，传统方法难以建立脉象特征与生理机制之间的定量联系，限制了脉诊理论的科学阐释。

第四，三部脉象割裂分析。寸口脉分为寸、关、尺三部，分别对应不同脏腑，但现有分析方法往往将三部脉象独立处理，忽视了它们之间的协同关系和相互影响。

第五，模型不可解释。纯数据驱动的深度学习模型虽然能在一定程度上实现脉象分类，但模型决策过程不透明，难以提供可解释的诊断依据，影响临床应用的可接受度。

综上所述，传统脉诊方法无法满足中医脉象客观化、机理可解释化和诊断智能化的需求，亟需一种将物理机制与数据学习有机融合的新方法。

## 四、发明内容（核心创新点，详细描述）

本发明提供一种基于偏微分方程（PDE）物理建模与物理约束神经网络（PINN）混合的脉象信号分析方法，其核心创新点包括以下几个方面：

**创新点一：基于动脉血管弹性力学的PDE脉波模型**

本发明建立了描述脉波在动脉血管中传播的偏微分方程模型。根据动脉血管的圆柱壳结构假设和弹性力学原理，脉波传播满足一维血流动量方程和连续性方程的耦合系统。具体形式为：

连续性方程：∂A/∂t + ∂Q/∂x = 0
动量方程：∂Q/∂t + ∂(αQ²/A)/∂x = - (A/ρ) ∂p/∂x - (8πμ/ρA) Q

其中A为血管横截面积，Q为体积流量，p为血管内压力，ρ为血液密度（≈1060kg/m³），μ为血液粘度（≈3.5×10^-3Pa·s），α为血流分布系数。血管壁弹性采用线弹性本构关系：p - p0 = K(A - A0)，其中K为体积弹性模量，A0为平衡截面积。

该PDE模型考虑了血管几何参数（长度、直径、壁厚）、材料参数（弹性模量、粘度）和血流参数（血液密度、粘度）的影响，可描述收缩期快速上升、舒张期缓慢下降的典型脉波形态。通过有限差分法或有限元法求解该PDE，可得到血管沿线各点的压力-时间曲线和流量-时间曲线。

**创新点二：基于PINN的物理约束神经网络融合**

本发明采用物理约束神经网络（Physics-Informed Neural Network，PINN）融合PDE物理模型与深度学习的优势。PINN网络结构包含特征提取层、物理约束层和输出预测层三部分。

特征提取层由4层全连接神经网络组成，每层神经元数量分别为128、256、256、128，使用tanh激活函数， dropout保留率0.8。输入为脉象压力信号的时序采样点（采样长度256点，对应约2秒信号），输出为64维特征向量。

物理约束层实现PDE残差计算。具体而言，将神经网络预测的压力p̂(x,t)和流量q̂(x,t)代入上述PDE方程，计算方程左右两边的残差：
r_c = ∂Â/∂t + ∂Q̂/∂x
r_m = ∂Q̂/∂t + ∂(αQ̂²/Â)/∂x + (Â/ρ) ∂p̂/∂x + (8πμ/ρÂ) Q̂
物理约束层的损失函数包含PDE残差的平方在时空域的积分。

输出预测层包含2层全连接网络，输出脉象特征参数（幅度、频率、斜率等）和证候分类结果。PINN的总体损失函数为：
L = λ1·Ldata + λ2·Lphysics + λ3·Lconsistency
其中Ldata为数据拟合损失（预测与真实标签的交叉熵），Lphysics为PDE残差损失，Lconsistency为物理参数一致性损失，λ1、λ2、λ3为权重系数，取值分别为1.0、0.5、0.3。

**创新点三：寸关尺三部脉象协同建模**

本发明提出三部脉象协同分析的数学模型。根据中医理论，寸关尺三部脉象反映不同脏腑功能状态，但共享同一肱动脉血流来源，因此存在物理上的耦合关系。

本发明建立三部统一模型，将寸口脉看作从肱动脉分叉后形成的三个独立而又耦合的"上游-下游"关系。设肱动脉压力为p_0(t)，则关脉压力p_g(t)与p_0(t)的关系可由PDE传递函数描述，寸脉和尺脉则受关脉分叉后流动的影响。

协同建模的具体方法为：分别建立三部脉象的独立PINN子网络，然后通过共享编码层实现特征融合。共享编码层包含肱动脉特征提取器，输出肱动脉整体状态向量，分别传递给三部子网络作为上下文输入。三部子网络同时预测本部脉象参数和相邻部的相互影响系数，实现协同推理。

该模型的输入为三通道脉象信号（每部256点），输出为三部脉象的独立特征参数加上3×3的耦合系数矩阵。

**创新点四：病机分类与脉象参数的因果归因**

本发明建立了从脉象参数到证候分类的可解释因果归因模型。因果归因模块采用因果图结构，表示为：
证候节点 → 脏腑功能节点 → 脉象参数节点
通过结构化学习确定节点间的因果强度。

归因算法采用基于梯度的方法（Grad-CAM）和基于注意力机制的方法相结合。对于任意输入脉象信号，归因模块输出每个输入时间点对最终分类结果的贡献权重，形成可视化的时间-重要性热图。同时，通过因果图的路径分析，识别影响分类的关键中间节点和可能的因果链条。

该模块还支持反事实分析，即"如果某个脉象参数改变，分类结果将如何变化"，为医师提供干预建议的参考。

## 六、具体实施方式

**实施例一：标准脉象采集与分析系统**

该实施例适用于中医门诊的常规脉象辅助诊断，具体步骤如下：

步骤1：患者取坐位或仰卧位，手腕垫高使桡动脉处于心脏水平位置。医师或患者将三探头脉象传感器（直径8mm，量程0-50kPa，灵敏度≥50mV/kPa）放置于寸口脉搏最强处，分别对应寸、关、尺三部。

步骤2：启动信号采集系统，采样频率设置为500Hz，每个通道采样时间不少于30秒。信号预处理包括：工频陷波（50Hz陷波深度≥40dB）、低通滤波（截止频率20Hz）、基线漂移校正。

步骤3：将预处理后的三通道脉象信号输入PDE物理引擎。物理引擎首先根据信号幅度和形态初步估计血管参数（直径、壁厚、弹性模量），然后求解PDE得到理论脉波曲线。物理引擎采用Crank-Nicolson隐式差分格式，时间步长Δt=2ms，空间步长Δx=1mm。

步骤4：将PDE理论曲线与实际采集曲线对比，提取残差信号。将残差信号与原始信号一并输入PINN网络。网络包含约5×10^6个可训练参数，采用Adam优化器，学习率从10^-3衰减至10^-5，共训练500个epoch。

步骤5：PINN输出寸关尺各部的脉象特征参数，包括峰值压力、舒张末压、脉压差、上升支斜率、下降支斜率、主峰时间、潮波高度、重搏波高度等。同时输出证候分类结果，采用中医证型编码体系（如脏腑辨证：肝阳上亢、心脾两虚等）。

步骤6：将分类结果和关键参数传递至因果归因模块，生成时间-重要性热图和因果路径图，作为辅助诊断的可解释依据输出。

该实施例的典型参数范围为：采样频率500Hz，信号长度30秒（15000点），PINN网络4层全连接结构(128-256-256-128)，训练epoch 500个，证候分类类别数不少于20种。

**实施例二：动态脉象监测与疗效评估系统**

该实施例适用于需要观察脉象动态变化的临床场景，如治疗过程监测和疗效评估，具体步骤如下：

步骤1至步骤4与实施例一相同，完成单次脉象分析。

步骤5：连续采集24小时动态脉象信号，采样频率100Hz，定时采样模式（每小时采集60秒连续信号）。存储设备采用嵌入式SD卡，支持不少于72小时连续记录。

步骤6：对24小时脉象数据进行时序分析，提取以下动态指标：日间与夜间脉象差异、餐前与餐后变化趋势、运动后恢复时间常数、情绪波动相关变化等。

步骤7：建立个体脉象基线档案，记录正常状态下的脉象参数分布范围（均值±2标准差）。当后续测量结果超出基线范围时，系统自动标记并提示可能的生理或病理变化。

步骤8：支持治疗前后脉象对比分析，计算治疗前后各参数的变化率和统计显著性（t检验，P<0.05为显著），输出量化疗效评估报告。

该实施例的特有参数为：连续采集时长24小时，定时采样间隔1小时，每次采样时长60秒，动态指标计算采用滑动窗口法（窗口长度60秒，步进10秒），基线档案更新周期7天。

## 七、技术优势

本发明相对于现有技术具有以下显著优势：

**物理机理清晰**：PDE脉波模型基于严格的弹性力学和流体力学原理，可解释脉波形成的物理机制，为脉象分类提供生理学依据。

**数据效率高**：PINN融合物理约束，训练时不需要大量标注数据，物理损失函数的约束作用使网络在小样本条件下也能学习到合理的特征表示。

**可解释性强**：因果归因模块提供从输入信号到输出分类的完整因果链条，医师可理解模型"为什么"做出特定判断，增强临床应用的信任度。

**三部协同分析**：寸关尺协同建模考虑了脉象三部之间的生理耦合关系，避免了独立分析导致的信息丢失，提高了分析结果的全面性和准确性。

**动态监测能力**：支持24小时连续采集和时序分析，可捕捉生理节律和瞬时变化，为全天候健康管理提供数据支持。

**标准化输出**：脉象参数和证候分类采用标准化编码体系，便于多中心数据共享和横向对比研究。

## 八、可实验验证的指标（关键！必须列出明确的评价指标）

本发明以下列指标作为技术方案有效性的验证标准：

**脉象模拟误差RMSE**：通过PDE物理模型模拟产生的脉波曲线与实际采集信号的均方根误差。合格标准：RMSE<0.05（归一化信号幅度为0-1时的误差值）。

**脉象特征提取一致性**：同一受试者重复测量10次，比较特征提取结果的变异系数。合格标准：主要特征参数（峰值压力、脉压差、上升斜率）的变异系数CV<8%。

**证候分类F1值**：以3名副主任中医师的会诊结论为金标准，评估系统分类结果与金标准的一致性。合格标准：宏平均F1>0.82，微平均F1>0.85。

**PINN物理约束满足度**：计算PINN训练后PDE残差在测试集上的均值。合格标准：残差均值<0.01，表明物理规律被有效约束。

**因果归因可解释性评分**：由中医师评估归因热图和因果路径图是否能合理解释分类结果，采用5分制。合格标准：平均评分≥3.5分。

**三部耦合分析效果**：对比协同建模与独立建模的分类准确率，验证协同分析的增益效果。合格标准：协同建模准确率比独立建模提升≥5%。

**动态监测稳定性**：24小时连续采集后，比较首尾两时段信号质量（信噪比）。合格标准：信号质量下降<10%。

**系统响应时间**：从信号采集完成到分类结果输出的总延迟。合格标准：单次分析延迟<2秒，满足临床实时性要求。

上述指标将通过标准化的临床试验和仿真实验进行验证。仿真实验采用Customary开发的数字孪生脉象仿真器，产生符合生理规律的合成脉象信号。临床试验在具有GCP资质的中医院开展，纳入慢性疾病患者和健康志愿者，样本量根据统计功效分析确定（至少120例），盲法设计确保评估的客观性。
